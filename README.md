# 百炼中转工作台

独立服务器版 v1.1.0。提供阿里百炼模型中转、API Key 号池、加密 Key 包导入、中转 Key 管理和自定义计费。

## 已实现

- Key 号池：单个或批量录入、官方区域地址、备注、启停、优先级、自动轮转。重复凭据不重置用量。
- 每 Key 每模型分别设置总额度，查看已用、预占和可用；可修改新 Key 的默认预设。
- 支持拖拽上传或点击选择 Key 包文件，校验预览后确认导入。
- 沿用现有 `.aigckeypack` 的 Ed25519 验签和 AES-GCM 解密逻辑，包含现有客户解包材料。导入后按原包编号保留原文件备份，后台可下载。
- 文本普通响应及 SSE、单张图片、异步视频和任务查询。请求幂等，额度原子预占与结算。
- 创建独立中转 Key：复制、启停、名称、有效期、可用模型、初始人民币额度与增加额度。
- 自定义计费标准：文本按输入 / 输出百万 Token、图片按张、视频按分辨率和秒数；预占余额、按实际用量扣费，按 Key 查看账单。
- 管理员独立登录；中转 Key 仅能查询自身请求。阿里 Key、中转 Key、包备份与响应缓存在数据库中额外加密。

现有模型目录为 11 个：qwen-plus、qwen-max、qwen-image-3.0、qwen-image-3.0-pro、wan3.0-video、wan3.0-video-prime、happyhorse-1.0-i2v、happyhorse-1.1-i2v、happyhorse-1.1-r2v、wan2.7-i2v、wan2.7-r2v。模型实际权限与区域由阿里账号决定。

## 本机启动

需要 Node.js 24.x，无需安装 npm 依赖。在解压后的项目目录执行：

```sh
npm run init
npm start
```

打开 `http://127.0.0.1:3480`。账号 `admin`，初始随机密码见 `管理员登录.txt`。初始化不会把凭据打印到终端，再次初始化也不会覆盖现有凭据。

## Linux 服务器部署

推荐 Docker Compose + 附带的 Caddy HTTPS 配置；使用独立域名和根路径。

1. 将整个部署包解压到服务器专用目录，如 `/opt/bailian-relay`。需要 Docker Engine、Compose 插件，以及指向该服务器的域名。
2. 初始化凭据。如果服务器装有 Node 24，执行 `npm run init`；没有 Node 时执行：

```sh
docker run --rm -v "$PWD:/work" -w /work node:24-bookworm-slim node scripts/init.cjs
```

3. 编辑 `.env`，将以下两个值改成自己的域名，保留生成的密码、令牌和 VAULT_KEY：

```dotenv
PUBLIC_HOST=relay.example.com
PUBLIC_URL=https://relay.example.com
```

4. 确保域名已解析，服务器 80/443 端口可用，然后执行：

```sh
docker compose --profile https up -d --build
docker compose ps
docker compose logs --tail 80 relay
```

5. 通过 HTTPS 域名登录，在“计费标准”填写本站售价，导入 Key 包或添加阿里 Key 并检查逐模型额度；再到“中转 Key”创建调用凭据、授予初始额度和模型权限，复制 Key 与 Base URL 给调用方。

应用容器内端口为 3480，宿主机仅绑定回环地址；Caddy 负责公网 HTTPS。`relay_data` 为数据库持久化卷，重建容器不会清空。首次启动镜像需要从镜像仓库下载。

若已有 Nginx、宝塔或其他 HTTPS 入口：只执行 `docker compose up -d --build relay`，反代到 `http://127.0.0.1:3480`，保留原 Host，关闭流式响应缓冲，设置读取超时不少于 200 秒、请求体限制不少于 45MB。PUBLIC_URL 必须与浏览器访问地址完全一致。

## 中转计费

默认没有价格。空白表示该模型规格尚未配置，计费 Key 无法调用；明确填写 0 表示免费。修改价格只影响新请求，已提交请求保存原单价。增加额度是管理员在本站授予预算，不代表外部支付到账，也不向阿里充值。

原 RELAY_TOKEN 作为“旧版共享令牌”保留不计费行为。新调用方使用后台创建的计费 Key，迁移完成后可在后台停用旧令牌。详细口径见[计费与中转 Key](docs/计费与中转Key.md)。

## 上游额度口径

| 模型类型 | 每 Key 每模型默认总额度 | 结算方式 |
| --- | ---: | --- |
| 文本 | 100000 Token | 阿里返回的 usage.total_tokens |
| 图片 | 10 张 | 阿里返回的输出张数，缺省以结果图片数量核对 |
| Wan3 | 30 秒 | 输出视频实际秒数 |
| Wan2.7 | 50 秒 | 输出视频实际秒数 |
| HappyHorse | 10 秒 | 输出视频实际秒数 |

这是本站本地预算，不是阿里实时余额或免费额度。文本请求先按消息 UTF-8 字节量、协议余量和 max_tokens 预占；返回后按真实 Token 数结算。显式失败退回预占，断网、5xx、结果缺失或用量不明保留额度，在“请求与核对”中处理。若实际用量超出预占，仍如实记账并阻止后续超预算分配。

快速启动成本是现有机器资源；公网运行另需服务器与域名，实际模型调用由阿里计费。本次验收没有调用真实模型或产生模型费用。初始部署可按 1 核 / 2GB 内存作资源起点，属于工程预算而非性能承诺；应按实际并发做压测。
