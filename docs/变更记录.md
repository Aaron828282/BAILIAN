# 变更记录

## 2026-09-08：1.1.0 中转 Key 与计费标准

补齐调用方凭据环节：后台创建中转 Key，设置名称、初始人民币额度、有效期和模型权限，支持复制、增加额度、启停及按 Key 查看调用记录。调用方通过独立 Key 查询自己的余额、价目和账单。

新增自定义人民币售价：文本区分输入与输出百万 Token、图片按张、视频按分辨率和输出秒数。价格初始为空；零元必须显式填写。发送前在同一事务预占上游用量和调用方余额，完成后按价格快照结算，幂等重放不重复扣费，未知结果保留预占等待核对。

自动迁移历史数据库，旧请求归入旧共享令牌，保留历史用量和请求重放。旧令牌继续不计费，可在切换后停用。新中转 Key、余额、价格、消费流水和凭据密文随数据库备份恢复。

验收：21 个脚本语法检查、43 项自动测试全部通过；新增计费界面及原管理表单、拖拽导入的 Chromium 验收通过。使用隔离模拟数据，没有真实模型费用。容器启动仍需在目标服务器验证。

归档备忘：本次修正了“只有上游号池，缺少调用方凭据与计费”的业务缺口；售价由管理员填写，不预填示例价格，不代表阿里官方价格。


## 2026-09-08：Key 包拖拽上传

导入弹窗新增拖拽区域，保留点击选择文件。拖入后显示文件名、校验并预览，点击“导入并保存备份”后才入库。

接受单个 .aigckeypack 或 .json 文件，最大 5MB；拒绝多个文件、错误扩展名和空文件。连续选择文件时只采用最新解析结果；关闭弹窗后丢弃尚未完成的旧预览。导入弹窗打开期间防止浏览器直接打开被拖入的文件。

已完成真实 Chromium 拖拽事件、文件选择、校验、连续换包、导入备份、区域外拖放及手机布局验证。使用隔离模拟包，未写入正在运行的真实号池。3480 服务的脚本和样式已验证更新，无需重启。

归档备忘：点击与拖拽共用同一文件校验和预览流程；同一时刻仅允许最新文件成为待导入包。
