# 百炼中转工作台：范围与实现约定

独立服务器应用，保留中转、API Key 号池、每 Key 每模型本地额度、现有 .aigckeypack 解密导入、调用方中转 Key 与自定义计费。交付可部署文件，不改动现有公网与桌面项目。

采用 Node 24 内置 HTTP / SQLite，单实例事务持久化；Docker + 可选 Caddy HTTPS。数据层、Key 包与密钥保护、额度业务、协议中转、管理接口和前端分开。管理员使用独立登录会话；中转使用独立 Bearer 令牌。

号池按阿里官方接入域名与模型匹配，启停、备注、优先级、额度编辑。重复凭据不增加库存或重置额度。Key 和缓存结果在 SQLite 中额外使用 AES-GCM 加密；解包沿用客户验签公钥及拆分解密材料，不携带经营者签名私钥。

预置现有 9 个图像/视频模型和 qwen-plus / qwen-max 文本模型。默认图片 10 张，Wan3 30 秒，Wan2.7 50 秒，HappyHorse 10 秒，文本 100000 Token；全部是可编辑的本地预算，不是阿里实时免费额度。图像按输出张数，视频按输出秒数，文本按 usage.total_tokens 结算。

额度在发送前原子预占；明确失败释放，网络中断或用量不明保留预占并进入待核对。视频异步任务定时只读查询，重启可继续；发送中的请求重启后不重复生成。支持 Idempotency-Key，重复请求不再次扣占或再次发给阿里。

界面：浅灰蓝管理台、深蓝侧栏、青蓝操作色；号池表是主要内容，额度用“已用 / 预占 / 可用”的独立数值表达真实状态。导航包括号池、中转 Key、计费标准、额度预设、加密包、请求与核对、接口接入。无创作、作品库、商城、员工、代理或第三方模型。

验收使用随机测试密钥和模拟阿里接口，覆盖并发额度、错包、重复导入、故障、重启、鉴权、流式与异步任务。不得以模拟验证声称真实模型已调用。当前电脑无 Docker，因此需要清楚标注容器启动验证边界。
中转 Key 作为调用方身份，独立保存模型白名单、有效期、授予额度、已消费和预占。价格采用自定义人民币售价；没有默认价格，空白拒绝收费调用，显式 0 才免费。金额存为百万分之一元整数，运算采用 BigInt，避免浮点累计误差。请求保存价格快照，按原价结算；钱包与上游用量在同一 SQLite 事务中预占、结算。幂等键与请求查询按调用方隔离。原共享令牌保留不计费兼容，可停用。
