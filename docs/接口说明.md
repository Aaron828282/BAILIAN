# 百炼中转接口说明

所有调用均需发送中转 Key。推荐使用 `X-Relay-Key: <中转Key>`，也兼容 `Authorization: Bearer <中转Key>`。两种请求头同时存在时必须使用同一枚 Key，否则返回 `401 AUTH_CONFLICT`。Key 从管理员工作台“中转 Key”创建和复制。管理员 Cookie 不可替代中转 Key。基础地址为 `https://你的域名/v1`，另兼容 `/oai/v1` 前缀。

在 Dify 等变量编排平台中，推荐将纯中转 Key 保存为 Secret，并直接作为 `X-Relay-Key` 的值，避免拼接 Bearer 时引入空格、引号或换行。Key 不要放在 URL 参数或请求体中。

建议每次生成指定 `Idempotency-Key`（8—128 字符，字母、数字、下划线、点、冒号或连字符）。网络重试沿用原值；不同请求体复用同一值返回 409。处理中或待核对的原请求返回 202，已完成请求重放缓存。未提供时服务自动生成；调用方未保存原值时无法靠重试去重。

管理台为单管理员；可创建多个调用方中转 Key，分别管理余额、有效期和模型权限。幂等值按中转 Key 隔离，任务查询与账单只能查看本 Key 的记录。上游号池由服务器调度，不向调用方返回阿里 Key。

旧环境变量 RELAY_TOKEN 对应“旧版共享令牌”，保留原来的不计费行为及历史请求；可在后台停用。新创建的 Key 按本站自定义售价扣费。

## 模型目录

`GET /models` 返回当前中转 Key 获准使用的模型，表示本站协议支持，不代表上游阿里 Key 已开通模型。

## 余额、单价与账单

- `GET /balance`：返回 currency、mode、credit（累计授予）、spent、held、balance、available，金额单位为人民币元。旧令牌 mode=legacy，balance / available 为 null。
- `GET /pricing`：返回当前获准模型的自定义价格，basis=custom；文本 rates.input / output 为元 / 百万 Token，图片 rates.unit 为元 / 张，视频 rates.unit 为元 / 秒并带 resolution 对应的 variant。rates=null 表示未配置。
- `GET /usage?page=1`：每页 30 条自身请求记录，含 cost、reservedCost、billingUsage、状态与用量；cost=null 表示尚未结算或未计费。

本站消费与阿里官方账单分开，完整说明见[计费与中转 Key](计费与中转Key.md)。

## 文本

`POST /chat/completions`

```json
{"model":"qwen-plus","messages":[{"role":"user","content":"你好"}],"max_tokens":1024,"stream":false}
```

支持 qwen-plus / qwen-max。消息为 system/user/assistant 的纯文本字符串，最多 100 条。默认 max_tokens=2048，范围 1—32768；上游模型可能有更低限制。可传 temperature（0—2）、top_p（大于 0 至 1）。

`stream:true` 输出 SSE，自动要求上游返回用量；只有收到合法实际用量后才结束为 `[DONE]`。中断或用量缺失会输出 RESULT_UNKNOWN 并保留额度。最多缓存 2MB SSE 内容。相同幂等请求重放原 SSE。

暂不支持 tools、结构化输出、视觉消息、Responses API 或任意未知透传参数。请求体上限 1MB。上游预算按实际 `usage.total_tokens` 计账；收费还要求完整输入和输出 Token 分项，缺失时进入待核对。

## 图片

`POST /images/generations`

```json
{"model":"qwen-image-3.0","prompt":"一间简洁明亮的书房","size":"1024*1024","n":1,"watermark":false}
```

也支持 qwen-image-3.0-pro。每次一张；可选 `reference_images`，最多 3 张图片 Base64 data URL，单图最多 10MB；沿用现有客户端的参考图子集。可选 prompt_extend，默认 true；watermark 默认 false。

响应：

```json
{"id":"req_xxx","created":1780000000,"data":[{"url":"https://..."}],"usage":{"output_image_count":1}}
```

仅转发结果链接，不下载、托管或建立作品库。图片和视频请求 JSON 体积上限 45MB。

## 视频

`POST /videos/generations`

```json
{"model":"wan3.0-video","prompt":"镜头缓慢推进，窗边树叶随风轻摇","duration":5,"resolution":"720P","ratio":"16:9","watermark":false}
```

duration 为明确整数秒，默认 5；不接受自动时长 -1，以便预占额度。Wan3 为 2—30 秒；HappyHorse 为 3—15 秒；Wan2.7 为 2—15 秒，r2v 含参考视频时最多 10 秒。输入素材与分辨率由模型规则校验。

图生视频模型必须提供一张首帧，参考生视频模型必须提供参考素材。图片可用 reference_images 中的 Base64 data URL，或 media 中的公网 HTTPS 地址：

```json
{"model":"happyhorse-1.1-i2v","prompt":"人物自然回头","duration":5,"resolution":"720P","media":[{"kind":"image","url":"https://你的素材域名/frame.png","mimeType":"image/png"}]}
```

i2v 的画幅随首帧，不向上游发送 ratio。视频和音频参考仅接受公网 HTTPS URL，并提供 kind（video/audio）、mimeType、durationSeconds（1—15）；按模型素材规则限制数量和总时长。素材 URL 直接交给阿里，服务器不抓取素材。不支持本地音视频上传、尾帧与 first_clip 模式、文档或网页参考。

提交返回 202：

```json
{"id":"req_xxx","object":"video.task","status":"submitted","upstream_task_id":"阿里任务ID"}
```

使用 `GET /tasks/req_xxx` 查询，也可传关联的阿里任务 ID。后台每 15 秒查询一批最多 20 个视频任务，重启后继续查询。状态：sending、submitted、unknown、succeeded、failed、reconciled。成功返回 output.video_url 和 usage；普通文本、图片也可通过对应 req ID 查询已保存结果。

视频按 `usage.output_video_duration` 计本地秒数；只有旧响应缺少此字段时才回退到 duration。此口径是输出时长预算，参考素材计费、分辨率差异、阿里账户其他调用不纳入该本地预算。阿里提供的任务及结果 URL 有时效，请调用方及时取走。[官方 Wan3 说明](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)

## 故障行为

| 场景 | 行为 |
| --- | --- |
| 中转 Key 无效、停用或过期 | 401 UNAUTHORIZED |
| 中转 Key 无模型权限 | 403 MODEL_FORBIDDEN，未发送给阿里 |
| 未配置所选模型规格的价格 | 503 PRICE_NOT_CONFIGURED，未发送给阿里 |
| 中转 Key 可用人民币余额不足 | 402 INSUFFICIENT_BALANCE，未发送给阿里 |
| 无启用且额度充足的上游 Key | 429 POOL_UNAVAILABLE，未发送给阿里 |
| 阿里明确 4xx 拒绝（408 除外） | 502，退回预占，该 Key 冷却 60 秒 |
| 断网 / 超时 / 5xx / 用量不明 | 502 RESULT_UNKNOWN，保留预占 |
| 视频明确失败或取消 | 退回预占 |
| 请求提交期间服务退出 | 重启后为 unknown，不再次生成 |
| 视频任务超过 24 小时仍未结算 | unknown，保留预占，由管理员核对 |

本地请求 ID 同时出现在 `X-Request-Id` 响应头。没有自动重发 POST；冷却只影响后续新请求。每个上游阿里 Key 最多两个尚未结算请求，unknown 也占用这个并发名额。

参数适配参照阿里官方文档：[文本](https://help.aliyun.com/zh/model-studio/text-generation)、[千问图片](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)、[HappyHorse 首帧](https://help.aliyun.com/zh/model-studio/happyhorse-image-to-video-api-reference)、[Wan2.7 首帧](https://help.aliyun.com/zh/model-studio/image-to-video-general-api-reference)。本站实现上述明确子集，未声称覆盖各模型全部能力。

## 后台管理接口

以下接口要求管理员 Cookie，写操作还要求本站 Origin 与 X-CSRF-Token。不得将管理员会话发给调用方。

| 方法与路径 | 作用 |
| --- | --- |
| GET /api/relay-keys?page=1 | 每页 20 个中转 Key，返回脱敏凭据与余额 |
| POST /api/relay-keys | 创建，参数 label、credit、models、可选 expiresAt（毫秒时间戳或 null） |
| PATCH /api/relay-keys/:id | 编辑名称、enabled、models、expiresAt；credit 如提供，表示累计授予总额 |
| POST /api/relay-keys/:id/credit | 增加额度，参数 amount，必须大于 0 |
| POST /api/relay-keys/:id/token | 管理员查看完整 Key，写入审计记录 |
| GET /api/pricing | 查看所有模型规格的价格 |
| PATCH /api/pricing | 保存 items 数组；每项 model、variant、rates。文本 rates 含 input/output，其他含 unit；全部字段为 null 表示未配置 |
| GET /api/requests?relayKeyId=:id | 按中转 Key 筛选请求 |

后台额度和单价支持最多六位小数。价格写入为原子操作，一项无效时整批不保存。
