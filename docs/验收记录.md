## 覆盖的关键边界

- 同一凭据重复导入不增加额度，不抹掉已用；相同 Key 不允许静默切换区域。
- 并发请求只能在剩余预算范围内预占；八个并发图片请求争用一张额度时，仅一个发往模拟上游。
- 发送中退出的请求重启后保持预占并进入待核对，已有视频任务 ID 保留。
- 篡改包编号、错验签材料、错解密材料、未知模型和非阿里接入地址均拒绝。
- 包原始编号和原文件保留，下载与导入文件完全一致；SQLite 内存储额外加密的内容。
- 阿里 401、503、网络中断、实际超时、缺少 Token 用量、视频失败或过期分别验证。
- SSE 跨数据块读取和流式结果重放通过，缺少 usage 不输出成功结束标记。
- 全部七个视频模型请求计划验证；公网参考图不会被误当成空 Base64，i2v 不发送 ratio。
- SQLite 一致性备份能恢复原 Key 数和累计用量；错误 VAULT_KEY 拒绝启动并释放数据库句柄。
- 管理员登录与中转令牌隔离；CSRF、Origin 和私有文件静态路径隔离通过。
